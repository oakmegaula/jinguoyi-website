# 表單 → Google Sheet 部署步驟

網站的「免費品牌健檢」表單目前只有前端假送出（顯示感謝訊息，資料不會送到任何地方）。
照下面步驟部署完，就能讓表單資料即時寫進你自己的 Google Sheet。

## 步驟

1. 到 https://sheets.google.com 開一個新的 Google Sheet，命名例如「金菓薏官網表單」。
2. 上方選單「擴充功能」→「Apps Script」。
3. 把預設的 `Code.gs` 內容全部刪掉，貼上本資料夾 `Code.gs` 的內容。
4. 按 Cmd/Ctrl + S 存檔（專案名稱可自訂，例如「金菓薏表單接收」）。
5. 右上角「部署」→「新增部署作業」。
6. 類型選「網頁應用程式」（Web app）。
7. 「具有存取權的使用者」選「所有人」（Anyone）— 這樣網站才能匿名把資料送進來。
8. 「執行身分」選「我」（你自己的帳號）。
9. 按「部署」，第一次會跳出 Google 授權畫面，選你的帳號並允許存取。
10. 部署完成後會拿到一組網址，長得像：
    `https://script.google.com/macros/s/AKfycb.../exec`
11. 把這組網址提供給我（或自己貼到 `assets/js/main.js` 最上面的 `GOOGLE_SHEET_WEBHOOK_URL` 變數），
    然後把改動 push 上 GitHub，表單就會開始把資料寫進你的 Sheet。

## 之後要修改程式碼

如果之後要調整 `Code.gs`（例如加欄位），改完存檔後要：
「部署」→「管理部署作業」→ 編輯（鉛筆圖示）→「版本」選「新版本」→ 部署。
網址通常不會變，不需要重新回來改網站端的 URL。

## 資料表欄位

| 欄位 | 說明 |
|---|---|
| 時間 | 表單送出的時間戳記（自動產生） |
| 姓名稱呼 | 填表人姓名 |
| 品牌服務類型 | 例如：電商、餐飲、美業 |
| 粉專連結 | 客戶的 Facebook / Instagram 連結 |
| 是否買過假粉 | 是／否 |
| 每月預算 | 每個月廣告行銷預算 |
| 聯絡方式 | 電話或 Email |
| 需求項目 | 勾選的服務項目，以「、」分隔 |
| 來源頁面 | 是從網站哪一頁送出的（例如 /index.html） |
